## The entry

`main.ts` (Node 22, standard library only) writes one line of text — 1 to
240 characters — to `/output/entry.txt`: a quiet, earned moment of pride
for someone in a scene. A learner driver who failed her test four times
finally passes, and the pride is felt, never stated: her father lets go of
the door handle, and she drives them both home in the rain.

## Run it

```sh
node main.ts
```

The program verifies the line is a single line of 1–240 characters before
writing it, and prints the character count on success.
